# FOOTBALL LEAGUE MANAGEMENT SYSTEM (FLMS)

## 1. Project Description

The Football League Management System (FLMS) is a web-based application developed to manage football league activities efficiently. The system provides a central platform for managing football clubs, players, seasons, match fixtures, match results and statistics.

The system is designed to reduce manual record keeping, improve data accuracy and make football league information easier to access and manage.

## 4. System Modules

1. **User Authentication:** Allows authorised users to log in and log out.
2. **Club Management:** Manages football club information.
3. **Player Management:** Stores and manages player records.
4. **Season Management:** Manages football league seasons.
5. **Match Fixture Management:** Records scheduled matches.
6. **Results Management:** Records match results.
7. **Statistics Management:** Manages football league statistics.

## 5. User Roles

- **Administrator:** Can add, view, update and delete system records.
- **Ordinary User:** Intended to access and view permitted system information.

## 6. Installation and Setup

1. Clone the project repository.
2. Navigate to the project directory.
3. Install Django:

   `pip install django`

4. Apply database migrations:

   `python manage.py migrate`

5. Create a superuser if one does not already exist:

   `python manage.py createsuperuser`

6. Start the development server:

   `python manage.py runserver`

7. Open the application in a browser:

   `http://127.0.0.1:8000/`

## 7. Project Purpose

The project was developed as an academic requirement to demonstrate the application of web development, database management, system authentication and CRUD operations in solving football league management challenges.
